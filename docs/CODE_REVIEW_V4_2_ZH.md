| 中 | 负责人筛选仅隐藏行，病例数仍显示筛选前数字；Clear filters 不清负责人 | 在计数和渲染前统一筛选；重置时清除全部筛选与选择 |

## 仍存在的边界

这是 synthetic-only prototype：没有真实 EHR、完整 FHIR profile/术语验证、跨机构患者/episode matching、真实认证、持久不可篡改审计或消息发送。`synthetic` 标签不是去标识化控制。多次完成检查会阻止结案并要求核对，而不是自动猜测归属。病理报告需求和 clinical sign-off 不能仅靠本原型证明。

源 Bundle 快照与人工操作的时间含义不同：前者决定演示证据状态，后者记录本次操作时间。刷新会清空所有会话操作；导出后不能作为临床审计使用。
