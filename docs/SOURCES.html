Evidence and provenance register

Checked 2026-11-06. Public sources motivate the design; none contain patient-level input to the synthetic cohort.

Clinical sources

  • S1 — USPSTF (2021). Colorectal Cancer: Screening. Supports the average-risk, asymptomatic screening context and ages 45–75. It does not prescribe our 14-, 30- or 90-day workflow thresholds.
  • S2 — JAMA Network Open (2023). Rates of Follow-up Colonoscopy After a Positive Stool-Based Screening Test Result for Colorectal Cancer Among Health Care Organizations in the US, 2017–2020. Motivation for an incomplete follow-up scenario. This is a mixed stool-test cohort, not a FIT-only estimate for all settings.
  • S3 — Corley et al., JAMA (2017). Association Between Time to Colonoscopy After a Positive Fecal Test Result and Risk of Colorectal Cancer and Cancer Stage at Diagnosis. DOI: 10.1001/jama.2017.3634. Observational association; not proof that delay causes cancer.
  • S4 — JAMA Network Open (2024). Development of a Follow-Up Measure to Ensure Complete Screening for Colorectal Cancer. Supports feasibility of a defined follow-up quality measure. Does not validate this implementation.
  • S5 — NCQA (2026). HEDIS MY 2027: What's New, What's Changed, What's Retired. Announces COF-E. Our indicator is not certified or presented as an exact reproduction of NCQA specifications. The traditional screening-coverage measure and follow-up completion are distinct.

Public map data

  • S6 — CDC dataset. PLACES county data, 2025 release. Dataset ID swc5-untb; COLON_SCREEN; state IA. Raw retrieval includes 198 rows (99 crude and 99 age-adjusted estimates). Only CrdPrv is used in the map. Source query: https://data.cdc.gov/resource/swc5-untb.json?%24limit=500&stateabbr=IA&measureid=COLON_SCREEN . The local manifest retains the raw-data checksum.
  • S7 — CDC definition. PLACES prevention measures. The measure is up-to-date colorectal screening coverage among ages 45–75, estimated from population surveys and demographic data. It is not a FIT-positive clinical care cascade.
  • S8 — CDC release notes. Current Release Notes. The 2025 release carries forward 2022 BRFSS colorectal-screening data. “2025 release” and “2022 source year” are both shown to prevent confusing publication with observation.
  • S9 — Geometry. Plotly county GeoJSON, also used in Plotly's county choropleth documentation. The downloaded US county dataset was filtered by state FIPS prefix 19. This is illustrative Census-derived geometry, not a current legal-boundary representation. No provider tiles or runtime map service are used.

Simulation assumptions, not sourced facts

The 6.8% positive-result input, return/referral/booking probabilities, demographic mix, diagnostic findings, barriers, calendar delays and workflow thresholds are declared simulation choices. The original proposal's broad “5–8% FIT positivity” range has not been established here as a universal estimate. Do not cite the simulation as prevalence, diagnostic accuracy, clinical validation, or improvement caused by Loop.

Modeling methods checked for the local experiment

  • statsmodels SurvfuncRight: right-censored survival estimation. Installed statsmodels 0.14.5 API checked.
  • scikit-learn LogisticRegression: regularized binary classifier. Installed scikit-learn 1.7.2 API checked; online stable docs may show a newer release.
  • scikit-learn data leakage guidance: training/evaluation separation.
  • scikit-learn probability calibration: reliability diagrams and probability scoring.

These are method references, not evidence that this model works on real patients. The written modeling protocol and generated report retain all synthetic evaluation results, including the stronger rule baseline.

V2 navigation evidence and modeling references

  • S10 — Coronado et al., Annals of Internal Medicine (2025). Patient Navigation to Improve Colonoscopy Completion After an Abnormal Stool Test Result: A Randomized Controlled Trial. DOI 10.7326/ANNALS-24-01885. One-year completion was 55.1% with navigation versus 42.1% with usual care (13.0 percentage points; 95% CI 6.5–19.4). Baseline predicted completion probability did not moderate the intervention effect. This supports testing navigation, not assuming a high-risk patient benefits more or importing its annual effect into the V2 180-day scenario.
  • S11 — Ganguly et al., Journal of General Internal Medicine (2026). Patient Navigation to Improve Colonoscopy Completion Following an Abnormal Stool-test Result. DOI 10.1007/s11606-025-10151-2. The positive-FIT subgroup was small (89 participants); navigation included scheduling, preparation and social support. Used to motivate task types, not to calibrate simulator effects or claim clinical validation.
  • scikit-learn ensemble methods and permutation feature importance. Fixed random-forest parameters are specified in the V2 protocol. Validation permutation importance is descriptive, not causal, and is not used to select features after testing.

V2 default 85% task advancement, dedicated weekly capacity, task costs, missing-record probabilities, and latent needs are uncalibrated assumptions. The strong simulated default improvement must not be reported as expected clinical effect. V2 uses a custom discrete-event queue; no SimPy dependency or validation is claimed.
